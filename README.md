# Samurai Ghost Prototype (Godot 4)

Ghost of Tsushima inspired 3D samurai game prototype.

## Mobile Controls
- Left side: Virtual Joystick (move)
- Right side: Drag to look
- Attack Button: Katana attack

## Setup
1. Open in Godot 4.2+
2. Add your GLB models to assets/ folders
3. Press F5 to play

## Features
- Mobile virtual joystick
- Cinematic intro
- English story/dialogue system
- Third-person camera
